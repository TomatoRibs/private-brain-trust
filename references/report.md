# 报告

建议说完直接生成，一页 HTML。**不问「要不要」，不等他点头。**

---

## 一、六节，顺序不许改

先给答案，再给证明。改动顺序等于让他先读三屏才看到结论。

| 节 | 装什么 |
|----|-------|
| 抬头 | 他那句话当标题（不提炼）、建议条（砖红上下细线）、三格数据：现金能撑多久 / 观察期多长 / 复看日 |
| 01 结论摘要 | 一句话判断 + 三条编号理由 + 三条编号撤回条件 + 认一处输 |
| 02 前提盘点 | 四格数据 + 「最怕的那一件事」原话单独一行 + 现金跑道图 + 两怕对照图 |
| 03 四个视角 | 站位标尺图 + 四张卡（视角名·人物 → 当时那一问 → 他的原话回答 → 一句判断），主推卡左侧一道砖红竖线，全页只一道 |
| 04 冲突点 | 两处真对立左右对照，底部一句「所以他们不投票」 |
| 05 反方检查 | 担心事项状态图 + 三问逐条给结论 + 认输框（浅红底） |
| 06 结论 | 时间轴 + 大字建议 + 撤回条件 + 复看日 |
| 附录 | 四视角的方法出处与失效条件、诚实边界，默认折叠 |

## 二、四张图，不许纯文字堆叠

| 图 | 画什么 | 取数 |
|----|-------|------|
| 现金跑道 | 一条长条代表能撑的月数，砖红小段标出观察期 | 他说「20 个月」→ 刻度 0–20，四周约占 5% |
| 两怕对照 | 两行：怕留（实线砖红）、怕走（虚线灰） | 他先说哪个、最后确认哪个，后者标「主怕」 |
| 四视角站位标尺 | 四个圆点落在「现在就做 ←→ 先不动」的轴上 | 按每个视角的回答倾向摆位，**必须注明「按你的回答摆的，不是打分」** |
| 担心事项状态 | 三行空心点，未发生写「尚未发生」，右下角计数 0/3 | 反方检查那一问的回答 |

图表三条底线：

一、**只画问出来的事实。** 他没有的数字不许补，宁可少一张图。
二、**定性图必须说明不是打分。** 否则读者会把它当量化结论。
三、**图与正文建议必须一致。** 图说偏保守，正文就不能写「可以放心走」。

## 三、两条踩过坑的硬规则

**一、内容必须默认可见。** 报告是交付物，不是网页演示。不许让任何正文或图表依赖 JavaScript 才显示。

预览面板、iframe、打印、截图工具里，滚动监听常常不触发。曾踩过：卡片设 `opacity:0`，靠脚本加 class 才显示，结果用户打开是一整页空白。

所以：内容默认 `opacity:1`，图表默认处于最终状态，动画只用纯 CSS 跑完，**绝不拿 JS 切换可见性**；入场动画首帧也别用 0，用 0.6。

**二、生成后必须验。** 不注入任何 class、不滚动，直接量：

```js
[...document.querySelectorAll('.reveal')].filter(e=>getComputedStyle(e).opacity>.9).length
getComputedStyle(document.querySelector('.rw-fill')).width
```

前者应等于总数，后者应等于轨道宽。1280 与 390 两个宽度都不能有横向溢出。

## 四、视觉

| 项 | 值 |
|----|----|
| 底 | `#FAF8F3` 暖白 |
| 卡面 | `#FFFFFF`，1px `#E2DACB` 边框，圆角 6px |
| 正文 | `#1A1815`；次要 `#6B6357` |
| 数据色 | `#4A6670` 青灰，只用于图表 |
| 强调 | `#B3402F` 砖红，只用于建议条、主推竖线、认输框、触发节点 |
| 标题 | Songti SC 600；正文 PingFang SC 400；数字等宽 |

正文单栏 720px 居中，左侧固定目录（窄于 1200px 隐藏），顶部 2px 进度线。主标题 52px 且**禁止手写换行**（让浏览器自己断，手写 `<br>` 会把词拆开）。

不用：渐变、重阴影、超过 6px 的圆角、图标库、emoji、外链资源。图表用纯 CSS 加内联 SVG，离线能开、能打印。

## 五、写文案的规矩

- 判断句用陈述句，不写「可能」「或许」「建议考虑」。
- 引用他的话一律加引号，一个字不改。四个视角里的「回答」没有一个可以替他写。
- 每节导语只准一句，超过就删。
- 图表旁必须有一行说明数据从哪来。
- 全篇不出现「AI」「大模型」「提示词」。
- 脱敏默认关。只给自己看就用真名真金额；他主动说会给别人看，才走脱敏（真名换角色、公司换行业、金额换区间、城市换层级），并把开关状态写进页脚。

---

## 六、交付前自检

- 六节齐、顺序没动；结论摘要在最前面，不往后翻也能读懂。
- 建议口吻，无裁决词；三条理由、三条撤回条件都编号。
- 三条理由来自不同视角，没有同一个视角占两格。
- 四张图齐，只画了问出来的事实，定性位置标了「不是打分」。
- 冲突点有一处真对立，不是硬凑；反方检查有一处认输。
- 不注入任何 class 的情况下，全部内容可见。
- 页脚有版本、脱敏开关状态、日期。

---

## 七、诚实边界

**不承诺好看。** 能保证的是结构清楚、来源可追、三个月后还看得懂；保证不了谁会因为这份报告改变决定。

**图表不改判断。** 某一节没内容可放，说明那一步推演没做扎实，回去补推演，别用图形和形容词把版面填满。

**报告不代替执行。** 怎么谈、怎么辞、怎么签，不在本包范围内。
